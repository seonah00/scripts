# GlobalViral — 수강생용 글로벌 콘텐츠 작업실

## 목표

수강생이 제품·매장 정보 또는 브이로그·일상 이야기를 확인하고 틱톡(미국)과 샤오홍슈용 콘텐츠를 기획합니다.
운영자 소유 웹주소에서 이메일 계정으로 로그인하고 본인의 작업을 저장합니다.

## 이용 흐름

1. 이메일·비밀번호로 가입하고 인증 메일을 확인합니다.
2. 운영자가 가입 이메일과 수강 정보를 확인해 승인합니다.
3. 승인된 수강생이 플랫폼, 카드/영상 형식, 제품·매장, 실제 사용 여부를 선택합니다.
4. 공식 정보·후기·개인 경험을 구분해 입력하거나 AI 조사를 요청합니다.
5. 사용할 정보를 직접 확인하고 기획 방향을 고릅니다.
6. 외국어 콘텐츠, 한국어 의미, 촬영 방향을 편집합니다.
7. 표현 검토에서 과장·보장·의학적 효능·외부 구매 유도 등 문구를 확인합니다.
8. 프로젝트를 저장하고 다음 로그인에서 이어서 작업합니다.

## 역할

| 역할 | 이용 범위 |
| --- | --- |
| 비회원 | 가입·로그인·비밀번호 찾기 |
| 승인 대기 수강생 | 대기 화면·로그아웃·비밀번호 변경 |
| 승인된 수강생 | 콘텐츠 기획·표현 검토·본인 프로젝트·프로필 |
| 이용 중지 수강생 | 중지 안내·로그아웃·비밀번호 변경 |
| 운영자 | 작업실 및 수강생 승인·중지 관리 |

최초 운영자는 데이터베이스에서 명시적으로 설정합니다. 회원가입 입력으로 관리자 권한을 받을 수 없습니다.
운영자도 일반 작업실에서는 자신의 프로젝트만 조회합니다. 학생 프로젝트 열람 기능은 제공하지 않습니다.

## 콘텐츠 원칙

- 실제 사용하지 않았다면 사용·구매·효과 경험을 만들어내지 않습니다.
- 사용자 확인을 거친 정보만 생성에 사용합니다.
- 출처가 있는 공식 주장과 타인의 후기를 구분합니다.
- 샘플은 가상의 사전 작성 콘텐츠임을 표시합니다.
- 표현 검토는 문맥 검토를 돕는 규칙 기반 보조 기능이며 플랫폼의 공식 적합성 판정이 아닙니다.
- 추가 기능 5개 중 표현 검토만 구현합니다. CTA 생성, SRT, PDF/Notion 내보내기, 트렌드 레이더는 제외합니다.

## 운영 설계

GitHub에서 소스를 관리하고 Railway에서 Next.js 서버를 실행합니다.
Supabase Auth가 인증을 처리하고 Postgres가 프로젝트·프로필·회원 상태·AI 사용량을 저장합니다.
서버 인증과 DB RLS를 함께 적용해 개인 데이터를 보호합니다.
AI 비밀키와 Supabase 서버 키는 서버 환경변수로만 관리합니다.
사용자별 AI 한도는 한국시간 하루 30회입니다. 호출 실패도 한도에 포함합니다.

## 이번 구현 범위와 남은 연결

소스·로그인/관리 화면·API·SQL·배포 설정과 로컬 검증을 완료했습니다.
지정된 Supabase scripts 프로젝트에 스키마를 적용했습니다. SMTP 설정·Railway 배포·OpenAI 연결은 남아 있습니다.
운영 요금, 도메인, 이메일 발신자, 최초 관리자 계정은 운영 환경을 연결할 때 확정합니다.

## 브이로그·일상 (2026-09-26)

이야기 제목, 실제 있었던 일·감정 또는 촬영 계획, 촬영 상태, 장면 목록, 분위기를 입력합니다.
입력한 이야기는 확인 체크 후 사용하며 실제 경험이 없는 계획은 과거 경험으로 작성하지 않습니다.
전용 구성은 하루 흐름·공감 순간·취향 기록 세 가지입니다.
샤오홍슈는 DeepSeek로 젊은 성인 독자에 맞는 자연스러운 중국어를 작성하고, 틱톡은 OpenAI로 미국식 구어체를 작성합니다.
직역을 피하고 최종 외국어 문구와 한국어 의미를 함께 맞춥니다. 특정 표현의 실시간 유행이나 성과는 보장하지 않습니다.
